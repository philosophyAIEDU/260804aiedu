# C층위(중도중복장애) 학생을 위한 AI 감각 창작 수업

특수교육 재활학교에서 진행 중인 프로젝트입니다. 최소 동작(시선 고정·스위치·단일 터치)으로
반응하는 C층위 학생이 태블릿으로 **감각 자극을 받고 → 자기 움직임이 화면을 바꾼다는 것을 알아차리고 →
그 궤적을 작품으로 남기는** 40분 수업의 설계안과, 수업에 쓰는 웹 창작 도구 프로토타입을 담고 있습니다.

수업 학습목표는 세 가지입니다.

1. 스누젤렌 기반 감각 경험과 각성 조절
2. 내 움직임(터치·스위치)이 화면·소리를 바꾼다는 인과 인식
3. 시선·움직임의 궤적이 이미지로 남아 저장되는 창작 경험

> **이 층위에서 AI를 쓰는 주체는 학생이 아니라 교사입니다.** 교사가 AI로 그 학생만을 위한
> 배경 영상·음원을 미리 만들고, 학생은 그것을 감각으로 경험하며 반응합니다.

---

## ⚠️ 수업 전 반드시 확인할 것

- **광과민성 발작 이력을 보건교사·보호자에게 사전 확인.** 확인 전 임시 기준: 깜빡임 초당 3회 미만,
  명도 대비 낮게, 소리 기본 off, 첫 회는 5분 이내로 시험 진행 후 반응을 보고 연장.
- 과각성 신호(근긴장 증가, 호흡 빨라짐, 시선 회피, 울음)가 보이면 **즉시 자극을 낮추고 중단.**
- 1회 15~20분 원칙. 자세 유지 부담과 피로도를 고려합니다.
- 학생 얼굴·음성·실명은 외부 AI 서비스에 업로드하지 않습니다.
- AI 생성 결과물은 학생에게 보여주기 전 교사가 반드시 사전 확인합니다.

자세한 내용은 [설계안](docs/) 3장을 참고하세요.

## 사용법 — 브라우저로 열면 끝

**설치할 것이 없습니다.** HTML 파일 하나에 배경 영상과 음악이 전부 내장(base64)되어 있어서,
파일을 더블클릭하거나 태블릿 브라우저로 열면 인터넷 없이도 그대로 동작합니다.

### 태블릿에서 쓰는 방법

1. `prototype/` 폴더의 HTML 파일을 태블릿으로 옮기거나, 배포된 주소로 접속합니다.
2. 브라우저를 전체화면으로 만듭니다. (아이패드 Safari → 공유 → "홈 화면에 추가"로 저장하면 주소창 없이 뜹니다.)
3. 소리가 나지 않으면 화면을 한 번 터치하세요. 브라우저 정책상 첫 터치 전에는 자동 재생이 막힙니다.
4. 오른쪽 위 **설정** 버튼에 교사용 조절 항목이 모여 있습니다.

### 조작 방법

| 입력 | 동작 |
| --- | --- |
| 화면 터치·드래그 | 궤적이 남습니다 |
| 스위치(기본: 스페이스바) | 화면에 도장이 하나 찍힙니다 |
| 선택 화면에서 스위치 | 불이 들어온 카드를 선택합니다 (v2·v3) |
| 설정 → ● 녹화 시작 | 화면을 녹화하고, 다시 누르면 파일로 저장됩니다 |

블루투스 스위치 어댑터는 보통 버튼을 **키보드 키**로 보내줍니다. 어댑터가 보내는 키에 맞춰
설정의 "스위치로 쓸 키"에서 스페이스바 / 엔터 / 방향키 중 하나를 고르세요.

### 교사용 설정 항목

| 항목 | 설명 |
| --- | --- |
| 터치 궤적 굵기 | 10~80 |
| 스위치 도장 크기 | 20~150 |
| 궤적 색 | 색상 선택 (도장 모양을 고르면 자동으로 바뀝니다) |
| 스위치로 쓸 키 | 스페이스바 / 엔터 / → / ← |
| 음악 선택 스캔 속도 | 1.5~5초. **학생 속도에 맞춰 늦추세요** (v2·v3) |
| 화면 지우기 | 궤적만 지우고 배경은 유지 |
| 음악 / 도장 모양 다시 고르기 | 선택 화면을 다시 띄웁니다 (v2·v3) |
| ● 녹화 시작 | 결과물 저장 |

### 저장되는 결과물

녹화를 멈추면 `c_layer_artwork_(숫자).mp4`(또는 `.webm`) 파일이 자동으로 내려받아집니다.
배경 영상 + 학생이 남긴 궤적이 합쳐진 영상입니다. 수업 마무리 단계에서 학생과 함께 재생해 보세요.

> 결과물은 **미적 완성도로 평가하지 않습니다.** 반응 빈도·지속시간·독립성 수준으로 기록합니다.
> 정답도 실패도 없고, 모든 반응은 유효한 표현으로 다룹니다.

## 웹앱 3개 버전의 차이

세 버전 모두 남아 있습니다. 학생 상태에 따라 더 단순한 버전이 나을 수 있어서
최신판만 쓰기보다 골라 쓰는 것을 전제로 합니다.

### v1 — 최초 프로토타입 · [`prototype/v1-prototype.html`](prototype/v1-prototype.html)

가장 단순합니다. 열면 배경 영상이 바로 재생되고, 터치하면 부드러운 빛 번짐이 남고,
스위치를 누르면 화면 위를 천천히 도는 위치에 동그란 도장이 찍힙니다.

- **음악 없음.** 선택 화면도 없습니다.
- 선택 부담 없이 감각 경험(수업 1단계 "수용")에만 집중시키고 싶을 때 적합합니다.

### v2 — 음악 선택 추가 · [`prototype/v2-music-picker.html`](prototype/v2-music-picker.html)

시작할 때 **선택 화면**이 두 번 뜹니다. 학생이 스스로 고르는 경험(수업 2단계 "우연적 발견")을 만듭니다.

1. **"어떤 음악을 함께 들을까요?"** — 따뜻한 소리 ☀ / 차분한 소리 ☾ / 맑은 소리 ✨
2. **"스위치를 누르면 어떤 모양이 찍힐까요?"** — 동그라미 ● / 별 ★ / 꽃 ✿ / 하트 ♥

카드를 직접 터치해도 되고, 카드에 차례로 불이 들어올 때(**스캔 방식**) 스위치를 눌러 고를 수도 있습니다.
스캔 속도는 설정에서 학생 반응 속도에 맞게 늦출 수 있습니다.

- 고른 음악이 배경에 반복 재생됩니다.
- 고른 모양이 **스위치 도장**에 적용됩니다. 다만 **터치 궤적은 여전히 부드러운 빛 번짐**입니다.

### v3 — 도장 모양 수정 · [`prototype/v3-stamp-shapes.html`](prototype/v3-stamp-shapes.html) — 최신

v2와 화면·기능은 같고, 한 가지가 달라졌습니다.

- **터치 궤적도 고른 모양(별·꽃·하트)으로 찍힙니다.** v2에서는 스위치를 눌렀을 때만 모양이 나오고
  손으로 그리면 그냥 번짐이라, 학생 입장에서 "내가 고른 것"이 손으로 그릴 때는 보이지 않았습니다.
- 터치를 끌 때 모양이 0.12초 간격으로 찍히도록 조절했습니다. 모양이 겹쳐 뭉개지지 않고
  하나씩 또렷하게 이어집니다.

**특별한 이유가 없으면 v3을 쓰세요.**

학생이 어느 쪽에 이완 반응을 보이는지 1단계에서 관찰해 두고 다음 회차 콘텐츠 기준으로 삼으세요.

## 기술 메모

- 순수 HTML/CSS/JavaScript 한 파일. 빌드 과정도, 외부 라이브러리도, 서버도 없습니다.
- 배경 영상 위에 궤적 캔버스를 겹쳐 `<canvas>`에 매 프레임 합성합니다.
- 녹화는 `canvas.captureStream()` + `MediaRecorder`. MP4를 먼저 시도하고 안 되면 WebM으로 저장합니다.
- 영상·음악은 base64 data URI로 내장 — 그래서 파일이 크지만(0.7~1.2MB) 오프라인에서 그대로 돕니다.

### 알려진 제약

- **녹화에 소리는 들어가지 않습니다.** 캔버스 영상만 녹화됩니다.
- 사파리(아이패드)에서는 MP4 대신 WebM으로 저장될 수 있습니다.
- 화면 크기를 바꾸면 그리던 궤적이 지워집니다. 수업 중에는 화면 회전을 고정해 두세요.

## 배포

Netlify에 GitHub 저장소를 연결하면 됩니다. 빌드 명령 없이 정적 파일을 그대로 올립니다.
설정은 [`netlify.toml`](netlify.toml)에 들어 있어서 Netlify에서 따로 입력할 것이 없습니다.

배포 후 주소:

- `/` — 도구 목록 랜딩 페이지
- `/prototype/v3-stamp-shapes.html` — v3 바로 열기 (확장자 없이 `/prototype/v3-stamp-shapes`도 됩니다)

> 저장소는 private이지만 **배포된 사이트 주소는 아는 사람이면 누구나 접속할 수 있습니다.**
> 현재 올라간 파일에는 학생 개인정보나 실제 학생 산출물이 없습니다. 앞으로 학생 결과물을
> 이 저장소에 올리지 마세요. 검색엔진 노출까지 막으려면 `robots.txt` 추가를 요청하세요.
